Kaoyan memorization review: a self-hosted spaced repetition site for exam notes

中文

Last updated 2026-11-01 · Apache-2.0 · Python 3.7+ · Flask 2.3.2

In short: memorization-review is a Flask web app you run on your own machine — drop note screenshots into data/<subject>/ and it picks the 30 notes to review today from a per-note weight and review interval, then adjusts both when you answer familiar, blur or strange.

"Spaced repetition schedule for my exam notes" — no timetable to build by hand. Every note starts at weight 1.0 and a 1-day interval; weight drives how often it is drawn, "familiar" doubles the interval and "strange" halves it and raises the weight.

How it decides which notes you see today

Each note carries two pieces of state: a weight and a review interval. A new subject starts every note at weight 1.0 and a 1-day interval; draws are weighted by that weight, so notes you marked "strange" come back sooner. Weights are clamped between 0.1 and 10, so one note cannot monopolise every session or sink out of view forever.

Three buttons are the entire feedback channel. Familiar multiplies the interval by 2 (cap 30 days) and decays the weight by np.exp(-0.1); blur multiplies the interval by 1.2 and the weight by 0.95; strange multiplies the interval by 0.5 (floor 0.1 day) and the weight by 1.5. In other words "familiar" pushes a note away and "strange" pulls it back. The logic lives in update_weight and select_images_for_review inside app.py.

FAQ

Spaced repetition schedule for my exam notes: which notes should I review today?

The app answers it for you: it draws 30 notes per session by default (the count=30 default in select_images_for_review), weighted by each note’s mastery weight. Notes you marked "strange" have higher weight and surface first, while "familiar" notes are pushed out to an interval of up to 30 days.

How can I track how well I know each note?

Every note keeps a weight from 0.1 to 10 in data/weights.json: higher means it needs more attention. The statistics page aggregates file counts and average weight per subject, and the weight-management page lets you inspect and adjust individual entries without touching the JSON by hand.

Is there a self hosted flashcard review site that takes screenshots instead of cards?

This one does exactly that: notes are image files under data/<subject>/, keyed as subject/filename, so a photo of a page is a note. Nothing is OCR-ed, so text inside images is neither searched nor deduplicated — the trade-off is zero authoring effort for zero text-level features.

Can I run it without internet access?

Yes. It is a Flask app with three pinned Python dependencies and no external service: install Flask 2.3.2, numpy 1.24.3 and Pillow 9.5.0, run python app.py, and open port 5000. The only network use is whatever your browser does to reach your own machine.

What do the familiar, blur and strange buttons actually change?

They change two numbers per note. Familiar: interval ×2 (cap 30 days), weight × exp(-0.1). Blur: interval ×1.2, weight ×0.95. Strange: interval ×0.5 (floor 0.1 day), weight ×1.5 (cap 10). Weights are always clamped to 0.1-10, so the queue stays bounded.

Where is my data stored, and what happens if I switch computers?

Everything is in the project’s data/ directory: weights.json plus one folder per subject holding the note images. Copy that directory and you have migrated; skip it and every note restarts at weight 1.0. There is no sync service and no account system.

Can I open it from my phone?

Only over the network your machine is on: the server binds 0.0.0.0:5000, so a phone on the same LAN can open the host’s IP. There is no authentication and no merge logic, so two devices editing at once will overwrite each other’s weights file — use a sync-capable tool if you need multi-device.

5 steps to run it

  1. pip install -r requirements.txt (Flask 2.3.2, numpy 1.24.3, Pillow 9.5.0).
  2. Make sure a writable data/ directory exists — mkdir data if not.
  3. python app.py, then open http://0.0.0.0:5000.
  4. Home → "管理系统" → "添加新科目", then copy that subject’s note images into data/<subject>/.
  5. Home → pick a subject → set the review count (30 by default) → start, and answer familiar / blur / strange; check the statistics page for progress.
